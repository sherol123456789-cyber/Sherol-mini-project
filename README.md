# Movie Ticket Booking System
Java + MySQL mini project for English movie ticket booking.

Features:
- View/search English movies
- Seat layout with booked/available seats
- Regular, Premium and VIP pricing
- Food combo
- Automatic total calculation
- Booking receipt
- Save/view/cancel bookings in MySQL

Run `database/movie_booking.sql`, then configure MySQL password in `src/DBConnection.java`.
Add MySQL Connector/J to the Java project classpath and run `MovieBooking.java`.
